Document Setup

This project defaults to the uploaded 8.5 × 11 in perfect-bound booklet format. The supplied guidelines specify 0.12 in bleed on every side and a 0.2 in safety inset from the trim line. Cover spine width depends on paper stock/page count, so enter the spine width from the current printer template.
Changing dimensions after designing can reflow content imperfectly. Create or confirm your exact printer template first, especially the spine thickness.

Export

Print PDF exports cover spreads followed by single inner pages in the project order. Digital Magazine Folder writes magazines / project-name / pages / 000.webp… plus a manifest for viewer.html.
The guidelines call for CMYK with the Fogra 39 profile, 300 dpi imagery, embedded fonts, minimum 6 pt type, and 0.25 pt or heavier lines. Browsers and jsPDF do not provide a reliable press-ready CMYK/Fogra 39 workflow, so use the built-in preflight as a layout check and run the final PDF through your print provider or prepress software before ordering.
